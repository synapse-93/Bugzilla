# Product Workflow

## Project

A workspace contains projects. Each project has members and issues.

## Issue

An issue contains:

- Title
- Description
- Type
- Priority
- Severity
- Status
- Assignee
- Labels
- Project
- Timestamps

## Collaboration

Users can comment on issues and see a chronological activity history.

## Status transitions

```text
OPEN
  ↓
IN_PROGRESS
  ↓
IN_REVIEW
  ↓
RESOLVED
  ↓
CLOSED
```

The UI should make the current state and next useful action obvious.

## Secondary capabilities

- Search and filtering
- Kanban board
- Dashboard metrics
- Analytics
- Watch/follow issues
- Mentions
- Smart triage suggestions
